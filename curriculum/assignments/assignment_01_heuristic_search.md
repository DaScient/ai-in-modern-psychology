# Assignment 1 — Implement a Heuristic Search Model

> Aligned with Chapter 2 of *AI in Modern Psychology*.

## Learning Goals

- Understand how symbolic AI represents a problem space.
- Implement and trace a simple heuristic-search algorithm.
- Reflect on the cognitive plausibility of search-based models.

## Task

1. Choose a small problem domain (e.g., the 8-puzzle, Tower of Hanoi, or a
   2-letter anagram solver).
2. Implement an A* search using `heapq` from the Python standard library only.
3. Define and justify an admissible heuristic.
4. Plot states-expanded versus problem size for several instances.
5. Write a 600-word reflection: in what ways does A* resemble — or fail to
   resemble — human problem-solving as described by Newell & Simon?

## Deliverables

- A single Python file `assignment_01_<your_name>.py`.
- A 600-word reflection in `assignment_01_<your_name>.md`.

## Rubric

| Criterion | Points |
|-----------|-------:|
| Correctness of A* implementation | 30 |
| Heuristic admissibility argued explicitly | 15 |
| Empirical analysis (plot + brief discussion) | 25 |
| Reflection quality | 25 |
| Code style and clarity | 5 |
