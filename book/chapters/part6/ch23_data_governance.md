# Chapter 23: Data Governance

## Learning Objectives

By the end of this chapter, you should be able to:

- Understand the key concepts introduced in *Data Governance*.
- Connect chapter content to computational implementations in `/code` and `/notebooks`.
- Identify ethical considerations relevant to this topic.

## Overview

Retention, minimization, deletion, and stewardship of psychological data.

## 23.1 Retention Policies

Default to the shortest defensible retention period; build deletion into the data lifecycle.

## 23.2 Data Stewardship

Named stewards, audit logs, and access controls anchor accountability.

## 23.3 Deletion Protocols

Cryptographic erasure, machine-unlearning, and model retraining each play a role.

## 23.4 Cross-Border Data Flows

Different jurisdictions impose different obligations; data-residency requirements complicate cloud deployments.
