# Figures

Vector diagrams (SVG / PDF) for the book live here.

Each figure should be:

- **Vectorized** (SVG preferred) so it scales cleanly
- **Captioned** in the referring chapter, not in the figure file
- **Open-licensed** (CC BY 4.0 or compatible) and attributed to its author

See open issues with the label `diagram` for community-drawn figures we are seeking.
